Privacidad de datos de salud en Estados Unidos

MiBienestar · Vigente desde: 8 de octubre de 2026 · Última revisión: 8 de octubre de 2026

Ámbito. Este aviso complementa la Política de Privacidad para residentes o usuarios protegidos por leyes estatales de privacidad de datos de salud de Estados Unidos. Se aplica cuando la legislación correspondiente alcance a MiBienestar.

1. Datos de salud del consumidor que tratamos

MiBienestar puede tratar información introducida o generada a partir de la interacción del usuario con la app, incluyendo peso, altura, IMC, perímetros, estimaciones de composición corporal, sueño, hidratación, nutrición, actividad física, objetivos y estimaciones derivadas de esos datos. No recopilamos datos de salud desde corredores de datos ni compramos historiales médicos.

2. Fuentes

  • El propio usuario, cuando introduce información o configura objetivos.
  • Resultados calculados localmente o en nuestros servicios a partir de datos facilitados por el usuario.
  • Datos técnicos estrictamente necesarios para prestar funciones solicitadas, como autenticación, sincronización, seguridad, suscripción y notificaciones.

3. Finalidades

  • Proporcionar cálculos, registros, objetivos, recordatorios y estadísticas de bienestar solicitados.
  • Sincronizar la cuenta y los datos entre dispositivos autenticados.
  • Proporcionar funciones Premium y análisis de comida o ejercicio mediante IA cuando el usuario los solicita.
  • Proteger la seguridad, prevenir abuso y mantener la integridad del servicio.
  • Cumplir obligaciones legales aplicables.

4. Categorías de datos de salud compartidas y proveedores

No vendemos datos de salud, no los compartimos para publicidad dirigida y no utilizamos geofencing alrededor de centros sanitarios. Cuando es necesario para prestar una función solicitada, pueden procesarse con proveedores las siguientes categorías: identificadores de cuenta/técnicos imprescindibles para autenticación y seguridad; datos de bienestar almacenados y sincronizados mediante Firebase; y, solo al solicitar IA, la descripción introducida y, para ejercicio, el peso necesario para la estimación.

Las categorías de terceros/procesadores que pueden recibir esos datos únicamente para operar el servicio son:

  • Google Firebase / Google Cloud: autenticación, Firestore, Cloud Functions, App Check, Installations y mensajería.
  • Google Cloud Vertex AI: únicamente para análisis de IA iniciados voluntariamente por usuarios Premium.
  • Google Play: gestión y verificación de suscripciones; MiBienestar no recibe números de tarjeta.

No existen afiliadas a las que MiBienestar ceda datos de salud para fines propios.

5. Consentimiento

Cuando la ley exige consentimiento para recopilar o compartir datos de salud del consumidor, se solicita de forma afirmativa y antes del tratamiento correspondiente. El usuario puede retirar el consentimiento para tratamientos futuros. Si el tratamiento es imprescindible para una función solicitada, retirar el consentimiento puede impedir seguir usando esa función.

6. Derechos, solicitudes y retirada del consentimiento

Cuando resulten aplicables el Washington My Health My Data Act (RCW 19.373), Nevada SB 370 (2023) u otra ley estatal equivalente, puede solicitar, según corresponda:

  • confirmación sobre si tratamos sus datos de salud;
  • acceso a esos datos y a las categorías de terceros con los que se hayan compartido;
  • corrección cuando proceda;
  • retirada del consentimiento y cese de recopilación o compartición futura;
  • supresión de los datos de salud, sujeta a excepciones legales;
  • recurso o apelación si una solicitud es denegada cuando la ley reconozca ese derecho;
  • no sufrir discriminación ilícita por ejercer sus derechos.

7. Otros estados de Estados Unidos y California

Las leyes generales estatales de privacidad, incluida la CCPA de California, dependen de sus respectivos umbrales, definiciones y excepciones y no se aplican automáticamente a todo desarrollador. Cuando alguna resulte aplicable a MiBienestar, se reconocerán los derechos exigibles en esa jurisdicción. MiBienestar no vende información personal ni la comparte para publicidad conductual entre contextos.

8. Menores

MiBienestar no permite el registro de menores de 14 años y no está dirigido a niños menores de esa edad. Si llegáramos a conocer que se han facilitado datos de un menor no autorizado, se adoptarán las medidas razonables para eliminarlos y bloquear la cuenta, sin perjuicio de las obligaciones legales aplicables.

9. Brechas de seguridad

Cuando una incidencia de seguridad esté sujeta a la normativa federal o estatal de notificación de brechas —incluida, cuando corresponda, la FTC Health Breach Notification Rule— se realizarán las notificaciones exigidas a usuarios y autoridades dentro de los plazos legalmente aplicables.

10. Cambios materiales

No ampliaremos categorías de datos de salud, finalidades o destinatarios sujetos a consentimiento sin realizar las divulgaciones y obtener los consentimientos adicionales que exija la legislación aplicable.

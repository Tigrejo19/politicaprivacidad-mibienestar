Política de Privacidad de MiBienestar

Versión de consentimiento: 2026-10-07
Última actualización: 7 de octubre de 2026

Esta Política explica de forma clara cómo MiBienestar trata los datos personales y de salud necesarios para prestar sus funciones de bienestar, nutrición, composición corporal, sueño, hidratación, recordatorios y funciones Premium. Se aplica el Reglamento (UE) 2016/679 (RGPD), la Ley Orgánica 3/2018 (LOPDGDD) y las demás normas aplicables.

Importante: MiBienestar no es un dispositivo médico y no diagnostica, trata, cura ni previene enfermedades o condiciones médicas. Sus cálculos y recomendaciones son orientativos. Para consejo, diagnóstico o tratamiento médico consulte a un profesional sanitario cualificado.

1. Responsable y contacto

El responsable del tratamiento asociado a MiBienestar es tigredev, desarrollador de la aplicación. Para privacidad, ejercicio de derechos o soporte puede escribir a leonardovalverde19@gmail.com.

2. Datos tratados

2.1. Cuenta y perfil

  • Correo electrónico y credenciales de autenticación gestionadas por Firebase Authentication. MiBienestar no almacena la contraseña en Firestore.
  • Nombre, nickname, edad, sexo y zona horaria.
  • Identificador interno de usuario de Firebase (UID).

2.2. Datos de salud y bienestar

  • Peso, altura, IMC, perímetros corporales, estimaciones de grasa corporal, masa grasa y masa magra.
  • Registros y objetivos de sueño.
  • Registros y objetivos de hidratación.
  • Objetivos de peso, actividad y nutrición.
  • Registros de nutrición y ejercicio que el usuario decida guardar.

2.3. IA opcional para usuarios Premium

Cuando el usuario solicita voluntariamente “Analizar comida con IA” o “Analizar ejercicio con IA”, el texto introducido se envía mediante Cloud Functions a Google Cloud Vertex AI. En el análisis de ejercicio puede incluirse el peso necesario para estimar el gasto energético. La zona horaria se utiliza para aplicar correctamente la cuota diaria. La ubicación configurada para el procesamiento de IA es la multirregión de la Unión Europea. No utilizamos estas funciones para publicidad ni para tomar decisiones con efectos jurídicos o equivalentes sobre el usuario.

2.4. Datos técnicos necesarios

  • Firebase Installation ID y zona horaria para sincronizar de forma fiable los recordatorios entre dispositivos.
  • Estado de capacidad de entrega de notificaciones y datos técnicos de planificación de recordatorios.
  • Datos de Firebase App Check para verificar que las solicitudes proceden de una instancia legítima de la aplicación.
  • Metadatos de suscripción de Google Play, incluido un token de compra y el estado de la suscripción. MiBienestar no recibe ni almacena números de tarjeta.

3. Finalidades y bases jurídicas

  • Datos de salud: se tratan con el consentimiento explícito del usuario, conforme a los artículos 6.1.a y 9.2.a del RGPD.
  • Cuenta y prestación del servicio: los datos estrictamente necesarios para crear, autenticar y mantener la cuenta se tratan para prestar el servicio solicitado y gestionar la relación con el usuario.
  • Seguridad y prevención de abuso: App Check, autenticación, controles de acceso y registros técnicos mínimos se utilizan para proteger el servicio y a sus usuarios.
  • Notificaciones: solo se activan cuando el usuario habilita la función y, cuando Android lo exige, concede los permisos correspondientes.

El consentimiento de datos de salud se solicita de forma separada de la aceptación de los Términos y Condiciones. MiBienestar registra en servidor la fecha y la versión de la política aceptada para poder demostrar qué consentimiento se otorgó.

4. Proveedores que procesan datos

MiBienestar utiliza servicios de Google como encargados o proveedores tecnológicos necesarios para prestar el servicio:

  • Firebase Authentication.
  • Cloud Firestore y Cloud Functions for Firebase.
  • Firebase Cloud Messaging, Firebase Installations y Firebase App Check.
  • Google Cloud Vertex AI para las funciones de IA solicitadas por el usuario.
  • Google Play Billing para la gestión de suscripciones Premium.

No vendemos datos personales ni de salud y no los utilizamos para publicidad dirigida. El tratamiento por Google se rige por sus condiciones, acuerdos de tratamiento de datos y mecanismos de transferencia internacional aplicables. Puede consultar información adicional en Privacidad de Firebase y Cloud Data Processing Addendum.

5. Seguridad

  • Las comunicaciones de la app utilizan TLS/HTTPS y la aplicación bloquea explícitamente tráfico HTTP en claro.
  • Firestore aplica reglas de mínimo privilegio y aislamiento por usuario.
  • Las Cloud Functions sensibles requieren autenticación y App Check cuando corresponde.
  • Los datos locales de MiBienestar quedan excluidos de las copias de seguridad y transferencias del sistema Android.
  • Las credenciales y claves privadas de despliegue no se incluyen en la aplicación ni en el repositorio.

6. Conservación y eliminación

Los datos se conservan mientras la cuenta esté activa y sean necesarios para las finalidades descritas. El sistema contempla la eliminación de cuentas con más de 24 meses de inactividad, sujeta a las comprobaciones y reintentos técnicos necesarios.

El usuario puede eliminar su cuenta y los datos remotos asociados directamente desde MiBienestar mediante la opción Eliminar cuenta. También puede iniciar una solicitud de eliminación desde nuestro recurso web: Eliminar cuenta y datos.

Cuando una obligación legal aplicable exija conservar información concreta durante un periodo determinado, se conservará únicamente lo estrictamente necesario y se informará de ello cuando corresponda.

7. Retirada del consentimiento

Puede retirar su consentimiento en cualquier momento. Dado que los datos de salud son necesarios para las funciones principales de MiBienestar, retirar ese consentimiento implica dejar de tratar dichos datos y puede requerir la eliminación de la cuenta y de los datos asociados. Puede hacerlo mediante la opción de eliminación dentro de la app o contactando con soporte. La retirada no afecta a la licitud del tratamiento realizado antes de retirarla.

8. Derechos

Puede solicitar acceso, rectificación, supresión, limitación, portabilidad u oposición cuando proceda, y retirar el consentimiento en cualquier momento. Para ejercerlos escriba a leonardovalverde19@gmail.com. Podremos solicitar información razonable para verificar la identidad, pero nunca solicitaremos su contraseña.

También puede presentar una reclamación ante la Agencia Española de Protección de Datos: www.aepd.es.

9. Menores

MiBienestar no permite crear cuentas a menores de 14 años. La aplicación valida esta edad mínima tanto en el cliente como en el backend.

10. Permisos y funciones del dispositivo

MiBienestar puede solicitar permiso para publicar notificaciones y autorización para programar alarmas exactas cuando sea necesario para los recordatorios. También utiliza WorkManager y, cuando procede, Firebase Cloud Messaging como mecanismos de recuperación y redundancia. No solicita permisos de ubicación para sus funciones actuales.

11. Cambios de esta política

Cuando un cambio de esta Política requiera renovar el consentimiento sobre datos de salud, la aplicación bloqueará las funciones de salud hasta que el usuario revise la política vigente y otorgue nuevamente su consentimiento explícito. La versión aceptada queda registrada en servidor.
